# Botpass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Dockerized fetch proxy that returns raw public HTTP(S) content, requires an API key, reuses Cloudflare cookies from PostgreSQL, and falls back to Botasaurus Chrome only after an HTTP block.

**Architecture:** A small FastAPI app authenticates each request then delegates synchronous fetching to one service module. The module validates each destination and redirect against SSRF address ranges, loads/stores per-host cookies and cached raw bodies in PostgreSQL, attempts Botasaurus Request first, then uses a browser session to get the raw response only for block responses.

**Tech Stack:** Python 3.12, FastAPI, Uvicorn, Botasaurus, PostgreSQL, psycopg, Docker Compose.

**Spec:** `docs/superpowers/specs/2026-09-06-botpass-design.md`

## Global Constraints

- Accept only absolute HTTP(S) URLs; only issue upstream GET requests.
- Reject loopback, private, link-local, multicast, unspecified, and reserved resolved addresses before every connection and redirect.
- Use PostgreSQL for the response cache and domain cookies; no Redis.
- Bound redirect count, response size, and duration; use raw upstream bytes rather than rendered browser DOM.
- Require `X-API-Key` to equal the `FETCH_API_KEY` environment variable; Compose must expose the service only on `127.0.0.1` by default.
- Browser bypass is best effort and cannot promise CAPTCHA or Cloudflare success.

```python
def validate_url(url: str) -> str:
    parsed = urlsplit(url)
    if parsed.scheme not in {"http", "https"} or not parsed.hostname:
        raise ValueError("url must be an absolute http(s) URL")
    validate_host(parsed.hostname)
    return urlunsplit(parsed)


def validate_host(host: str) -> None:
    for item in socket.getaddrinfo(host, None, type=socket.SOCK_STREAM):
        address = ipaddress.ip_address(item[4][0])
        if not address.is_global:
            raise ValueError("destination address is not public")
```
